Chen Notation with DOUBLE LINES (Total Participation)

📌 DOUBLE LINES in Your Schema (Required Relationships):

MUST Use DOUBLE Lines:

tasks → projects (Every task MUST belong to a project - ON DELETE CASCADE)
comments → tasks (Every comment MUST belong to a task - ON DELETE CASCADE)
comments → users (Every comment MUST have an author - FOREIGN KEY constraint)

Use SINGLE Lines:

projects → users (Project can exist without team lead - team_lead_id can be NULL?)
tasks → users (Tasks can be unassigned - assigned_to is NULL by default)

Rule: Use DOUBLE lines when foreign key is NOT NULL or has ON DELETE CASCADE. Use SINGLE lines when NULL is allowed.
